"# Quick Setup Guide - Armory Management System

## ⚡ Fast Setup (5 Minutes)

### Step 1: Setup Oracle Database (2 minutes)

```bash
# Connect to Oracle
sqlplus system/Oracle123@localhost:1521/XE

# Run this in SQL*Plus
@/app/armory-system/database/schema.sql

# Exit SQL*Plus
exit;
```

```bash
cd /app/armory-system/backend
npm start
```


## 🔧 Troubleshooting

### Oracle Not Running?
```bash
# Check Oracle status
lsnrctl status

# Start Oracle (if needed)
lsnrctl start
```

### Backend Won't Start?
```bash
# Check if port is in use
lsof -i :8001

# Kill process if needed
kill -9 <PID>

# Reinstall dependencies
cd /app/armory-system/backend
rm -rf node_modules
npm install
```

### Can't Login?
- Username: `admin`
- Password: `ad133`
- Make sure backend is running
- Check browser console for errors

### Database Errors?
```bash
# Reconnect to Oracle
sqlplus system/Oracle123@localhost:1521/XE

# Check if tables exist
SELECT table_name FROM user_tables;

# Re-run schema if needed
@/app/armory-system/database/schema.sql
```

## 🚀 Production Checklist

Before deploying to production:

- [ ] Change admin password in `.env`
- [ ] Update CORS settings in `server.js`
- [ ] Set up HTTPS/SSL
- [ ] Configure proper Oracle user (not system)
- [ ] Set up database backups
- [ ] Add logging and monitoring
- [ ] Implement rate limiting
- [ ] Review security settings

## 📞 Need Help?

Common issues:
1. **Can't connect to Oracle**: Check connection string in `.env`
2. **Tables not found**: Run schema.sql again
3. **Login fails**: Verify admin user was created
4. **CORS errors**: Check backend is running on port 8001
