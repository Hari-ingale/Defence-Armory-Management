## 🔧 Troubleshooting Guide

### Issue: Oracle Connection Failed

**Symptoms:**
```
Error: ORA-12541: TNS:no listener
```

**Solutions:**
1. Start Oracle listener:
   ```bash
   lsnrctl start
   ```

2. Check Oracle service is running

3. Verify connection string in `.env`:
   ```
   DB_HOST=localhost
   DB_PORT=1521
   DB_SID=XE
   ```

### Issue: Admin User Not Created

**Symptoms:**
```
Error creating admin user: table or view does not exist
```

**Solutions:**
1. Run schema.sql first:
   ```bash
   sqlplus system/Oracle123@localhost:1521/XE @/app/armory-system/database/schema.sql
   ```

2. Restart the server

### Issue: Port 8001 Already in Use

**Symptoms:**
```
Error: listen EADDRINUSE: address already in use :::8001
```

**Solutions:**
1. Find and kill the process:
   ```bash
   # Find process
   lsof -i :8001
   # or
   netstat -ano | findstr :8001
   
   # Kill it
   kill -9 <PID>
   ```

2. Or change port in `.env`:
   ```
   PORT=8002
   ```

### Issue: CORS Errors in Browser

**Symptoms:**
```
Access to fetch at 'http://localhost:8001/api/login' from origin 'file://' has been blocked by CORS
```

**Solutions:**
1. The backend has CORS enabled, this should not happen
2. If it does, use HTTP server method instead of direct file:
   ```bash
   cd /app/armory-system/frontend
   python3 -m http.server 3000
   ```

### Issue: Cannot Login

**Symptoms:**
- \"Invalid username or password\" message

**Solutions:**
1. Verify admin user exists in database:
   ```sql
   sqlplus system/Oracle123@localhost:1521/XE
   SELECT username FROM users;
   ```

2. Check credentials:
   - Username: `admin`
   - Password: `ad133`

3. Check backend logs for errors

### Issue: Weapon Already Issued Error

**Symptoms:**
- \"Weapon is already issued to another soldier\"

**Solutions:**
1. This is expected behavior - return the weapon first
2. Or use a different weapon ID

### Issue: Soldier Not Found

**Symptoms:**
- \"Soldier not found. Please register the soldier first.\"

**Solutions:**
1. Register the soldier before issuing weapons
2. Or use a pre-loaded soldier (SOL001, SOL002, SOL003)

## 🔐 Security Notes

**For Production Deployment:**

1. **Change Default Password**
   - Edit `.env`: `ADMIN_PASSWORD=<new-strong-password>`
   - Delete admin user from database
   - Restart server to recreate with new password

2. **Use Dedicated Database User**
   - Don't use 'system' user
   - Create specific user for the application
   - Grant only required permissions

3. **Environment Variables**
   - Never commit `.env` to version control
   - Use environment-specific configurations

4. **Enable HTTPS**
   - Use SSL certificates
   - Redirect HTTP to HTTPS

5. **Add Authentication Token**
   - Implement JWT tokens
   - Add token expiration
   - Implement refresh tokens
