## 📊 Database Schema

### Tables Created:

1. **USERS** - Admin authentication
   - user_id, username, password (hashed), role
   
2. **SOLDIERS** - Soldier records
   - soldier_id, name, rank, unit, phone, email, status
   
3. **WEAPONS** - Weapon inventory
   - weapon_id, weapon_type, serial_number, status
   
4. **WEAPON_ISSUE** - Issue/return tracking
   - issue_id, soldier_id, weapon_id, issue_date, return_date, condition, remarks

### PL/SQL Procedures:

1. **weapon_management_pkg.issue_weapon**
   - Issues weapon with transaction safety
   - Creates weapon if doesn't exist
   - Updates weapon status
   
2. **weapon_management_pkg.return_weapon**
   - Processes weapon return
   - Updates weapon status based on condition
   - Logs return information
